# Event wheel artwork

The original backgrounds were edited with the built-in image generation tool to remove decorative symbols. Original OSRS icons are separate image layers in the website.

## Background files
- public/hijgend-hert-sotw-wheel.webp
- public/hijgend-hert-botw-wheel.webp

## Prompts

### skill

Use case: precise-object-edit. Edit the supplied Hijgend Hert skilling wheel artwork. Remove ONLY all twelve small skill pictograms from the outer twelve wheel wedges (pickaxe, axe, hook, leaves, hammer, bow, fire, pot, rune stone, feather, butterfly, house). Fill each removed pictogram with the matching natural dark wood texture of its wedge. Leave all twelve wedge spaces completely blank. Preserve exactly the central crowned stag medallion, the entire circular wheel, every spoke, rim, support, perspective, size and position, the flags, lamps, forest courtyard and dusk lighting. Do not move, redesign, rotate or resize the wheel. Do not add any symbols, lettering or replacement icons. This is a clean background layer for precise original game icons to be placed by website code. Match the input 3:2 landscape framing.

### boss

Use case: precise-object-edit. Edit the supplied Hijgend Hert boss wheel artwork. Remove ONLY every monster pictogram from the twelve outer wheel wedges: dragons, demons, spiders, snakes, skeletons and bears. Fill those removed pictures with the matching blank burgundy or charcoal material of each wedge. All twelve wedges must be completely empty of creature drawings. Preserve exactly the central crowned stag medallion, the wheel outline, gold spokes, rim, pointed studs, stand, perspective, size and position, the flags, torches, castle courtyard and dusk lighting. Do not move, redesign, rotate or resize the wheel. Do not add any symbols, lettering or replacement icons. This is a clean background layer for precise original game boss icons to be placed by website code. Match the input 3:2 landscape framing.
