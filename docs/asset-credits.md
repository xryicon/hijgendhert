# Game artwork

`public/red-chinchompa.png` is the Old School RuneScape inventory icon for
item 10034, Red chinchompa. Game artwork belongs to Jagex.

- Icon source: https://static.runelite.net/cache/item/icon/10034.png
- Item reference: https://secure.runescape.com/m=itemdb_oldschool/Red+chinchompa/viewitem?obj=10034

The icon is used to mark Hunter competitions in the clan calendar.
